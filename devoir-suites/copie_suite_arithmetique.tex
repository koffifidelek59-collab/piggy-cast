\begin{center}{\Large\bfseries Exercice de maison}\end{center}

\textbf{1)} Pour $n = 0$ : $U_1 = U_0 - 7 = 3 - 7 = -4$.\\
Pour $n = 1$ : $U_2 = U_1 - 7 = -4 - 7 = -11$.\\
Donc $U_1 = -4$ et $U_2 = -11$.

\textbf{2)} Pour tout entier naturel $n$ :
$U_{n+1} - U_n = (U_n - 7) - U_n = -7$.\\
La différence $U_{n+1} - U_n$ est constante, donc $(U_n)$ est une suite arithmétique
de raison $r = -7$ et de premier terme $U_0 = 3$.

\textbf{3)} $(U_n)$ est arithmétique de premier terme $U_0 = 3$ et de raison $r = -7$, donc pour tout
entier naturel $n$ :
$U_n = U_0 + n\,r = 3 + n \times (-7)$.\\
Donc $U_n = 3 - 7n$.

\textbf{4)} Comme $r = -7$ et $-7 < 0$, alors la suite $(U_n)$ est décroissante.

\textbf{5)} $S = U_0 + U_1 + \dots + U_{100}$ est la somme de $100 - 0 + 1 = 101$ termes consécutifs
d'une suite arithmétique.\\
On a $U_0 = 3$ et $U_{100} = 3 - 7 \times 100 = -697$.
\[
S = (100 + 1) \times \frac{U_0 + U_{100}}{2} = 101 \times \frac{3 + (-697)}{2}
  = 101 \times \frac{-694}{2} = 101 \times (-347)
\]
Donc $S = -35\,047$.
